# Code Challenge – Landing Page

## Overview
Static landing page built from the provided desktop mock-up using Bootstrap 5.3 and SCSS.
The layout has been adapted for mobile devices.

## Tech Stack
- HTML5
- Bootstrap 5.3
- SCSS (using Bootstrap variables and maps)

## Notes on the Mock-up

### What works well
- Clear visual hierarchy between sections
- Consistent use of spacing and card-based components
- Good balance between text and imagery
- Modern and clean overall aesthetic

### What could be improved
- No comments. Every sections was easy to understand!
